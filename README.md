# Urtzi B — OPE Osakidetza

App de preparación para la OPE Osakidetza 2023·2024·2025  
**Batería Común Categorías C2, C3, D y E — Parte B (preguntas 151-300)**

## 📱 Cómo instalar

1. Sube todos los archivos a un repositorio GitHub
2. Activa GitHub Pages: **Settings → Pages → main → / (root)**
3. Abre la URL en Chrome del móvil/tablet
4. Toca **"Añadir a pantalla de inicio"** para instalarla como app

## ✅ Características

- **150 preguntas** oficiales OPE con respuesta correcta y explicación
- Modo secuencial o aleatorio
- Filtro por bloque temático
- **Guarda tus fallos** automáticamente en el dispositivo
- Botón "Repasar solo mis fallos"
- **Funciona 100% sin conexión** una vez instalada
- Optimizado para móvil, tablet y ordenador
